# Contributing

Open an issue describing the input, expected result and observed result. Use synthetic or public data; never include credentials or private portfolios.

Use Node.js 22 or newer. Run `npm test` and `npm run check` before opening a pull request. Keep API calls mocked in CI. Add regression tests for changes to payoff logic, exposure bounds, timestamps or provider validation. Clearly distinguish hypothetical data, observed facts, model judgments and user-reviewed premises. Do not describe synthetic test success as financial performance.
