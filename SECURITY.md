# Security

This prototype is intended for local, single-user use. Do not expose its HTTP port publicly. It implements no account authentication, custody or financial execution.

Never commit `.env`, credentials, exported private portfolios or API receipts containing private text. Public data and imported source text are untrusted. Jev output is not an authorization mechanism.

Report security issues privately through GitHub private vulnerability reporting if available. Otherwise contact the maintainer privately through their GitHub profile; do not put exploitable details or secrets in a public issue.
